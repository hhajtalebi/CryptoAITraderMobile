# تاریخچه، لاگ و خروجی

تحلیل‌ها، رویدادهای Paper/Backtest و logهای سطح INFO/ERROR در `cait.history` روی دستگاه ذخیره می‌شوند؛ محدودیت ذخیره: 200/500/500 مورد. `clearLogs` فقط لاگ را پاک می‌کند؛ `clearLocal` همهٔ داده‌های محلی این برنامه را حذف می‌کند.

صفحهٔ History:
- JSON: گزارش کامل تحلیل، Paper ledger، رویدادها و logها.
- CSV / JSONL / TXT: فقط نوع فعلی انتخاب‌شده در تب تاریخچه.

Exportها ممکن است اطلاعات شخصی یا پارامترهای تحلیل داشته باشند؛ پیش از ارسال بازبینی کنید. log server توسعه upstream failure را بدون body حساس گزارش می‌کند.
