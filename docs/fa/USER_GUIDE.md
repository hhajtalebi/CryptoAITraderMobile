# راهنمای کاربر

- داشبورد/بازار: قیمت‌های Spot عمومی و تایم‌استمپ منبع را می‌بینید.
- نمودار/تحلیل: تایم‌فریم Spot را انتخاب کنید؛ 15m/1h برای تحلیل به 4H confirmation معتبر نیاز دارند. دادهٔ ناقص/کهنه/گسسته به سیگنال معتبر تبدیل نمی‌شود.
- Futures scanner: وضعیت/قیمت/حجم/funding را جدا می‌خواند؛ چون کندل public تأییدشده نیست، سیگنال futures نمی‌سازد.
- Paper Trading: شبیه‌سازی محلی؛ Spot-long مجاز، short روی Spot رد می‌شود. هزینهٔ فرضی و لغزش اعمال می‌شوند. هیچ سفارش واقعی وجود ندارد.
- Backtest: TF را انتخاب، نرخ fee/slippage را تنظیم و اجرا کنید. هزینه‌ها در هر سمت اعمال می‌شوند؛ نتایج train/OOS مجزا و نمونه‌محورند.
- History: تب تحلیل/رویداد/لاگ را انتخاب کنید. JSON کل گزارش است؛ CSV/JSONL/TXT بر اساس تب انتخاب‌شده ساخته می‌شوند.
- دادهٔ واچ‌لیست و history روی همین دستگاه می‌ماند؛ پاک‌کردن storage یا uninstall آن را حذف می‌کند.
