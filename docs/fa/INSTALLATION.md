# راهنمای نصب و اجرا

## نصب APK روی Android

1. فایل `CryptoAITrader-v1.0.2.apk` را از پوشهٔ انتشار به گوشی منتقل کنید.
2. APK را از فایل‌منیجر باز کنید؛ در Android ممکن است نیاز باشد اجازهٔ «نصب برنامه ناشناس» را برای همان فایل‌منیجر بدهید.
3. نصب را تأیید کنید و برنامه را باز کنید.
4. برای دریافت بازار عمومی اتصال اینترنت لازم است. API Key لازم نیست.

فایل برای Android 5.0 (API 24) به بالا ساخته شده و شامل Java/WebView است، بنابراین فایل ABI جدا ندارد. برنامهٔ Android با امضای توسعه‌ای خودکار sandbox امضا شده؛ این کلید برای Play Store یا به‌روزرسانی‌های پایدار مالک کافی نیست. نصب واقعی روی گوشی یا emulator در این مرحله آزموده نشده است.

## اجرای سندباکس در رایانه

Node.js 20+ لازم است:

```bash
npm install
npm start
```

در مرورگر `http://localhost:4173/` را باز کنید. سرور توسعه مسیر proxy محدود به دو میزبان LBank را فعال می‌کند تا محدودیت CORS مرورگر تا حد امکان حل شود. اگر sandbox محیط به API عمومی دسترسی نداشته باشد، پیام خطا نشان داده می‌شود و قیمت خیالی تولید نمی‌شود.

فایل مستقل `sandbox.html` را هم می‌توان باز کرد؛ بسته به مرورگر، درخواست از پروتکل `file://` ممکن است به‌دلیل CORS رد شود. در این حالت از سرور محلی استفاده کنید.

## نیازمندی توسعه APK از سورس

نسخهٔ این تحویل با ابزارهای حاضر در محیط سازنده ساخته شد: OpenJDK 21، Android platform `android.jar` API 34، AAPT، Eclipse Compiler for Java، D8 و apksigner. این ابزارها بخشی از Android SDK استاندارد توسعه‌دهندهٔ نهایی نیستند. برای ساخت تکرارپذیر در checkout مشابه محیط سازنده:

```bash
npm test
python3 tools/build_release.py
```

در Android Studio معمولاً Android SDK Platform 35+، Build Tools و JDK 17/21 نصب شود. Flutter SDK فقط برای prototype قدیمی Flutter زیر `lib/` است؛ APK v1.0.0 از Android WebView shell ساخته می‌شود.

نسخهٔ 1.0.2 با targetSdk 34 و امضای v1/v2/v3 ساخته شده است. برای ارتقای نسخهٔ قبلی امضای سازگار استفاده شده؛ اگر نصب هنوز خطا داد، متن کامل خطای Android را بفرستید.
