# CryptoAITrader v1.0.1 — انتشار اصلاحی نصب

- نسخه: `1.0.1` (versionCode `10001`)
- هدف: سازگاری نصب و ارتقای نسخه روی دستگاه‌های Android
- APK با امضای v1/v2/v3 و کلید ثابت همین پروژه امضا می‌شود تا ارتقا از نسخهٔ قبلی با امضای یکسان ممکن باشد.
- targetSdk برابر 34 تنظیم شده است؛ minSdk برابر 24 است.
- معاملهٔ واقعی، API خصوصی و تضمین سود وجود ندارد.

## اعتبارسنجی
امضای APK، مشخصات manifest، صحت ZIP و checksum پس از ساخت ثبت می‌شوند. نصب روی گوشی فیزیکی در این محیط ممکن نبود؛ اگر نصب باز هم خطا داد، تصویر/متن دقیق خطای Android برای تشخیص لازم است.
